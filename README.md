# BiliVdl

一款独立开发的 Android 哔哩哔哩视频客户端与下载工具。

## 技术方案
- Kotlin：应用逻辑、网络与播放/下载业务
- Android XML：全部页面布局
- Material Components：原生控件与主题
- MVVM 分层：页面、数据、业务职责分离

## 开发阶段
1. 项目基础与整体 UI
2. 视频浏览与搜索
3. 视频播放、弹幕与评论
4. 视频下载系统
5. 账号与完整体验

## 构建
GitHub Actions 会在 push 到 main 或提交 Pull Request 时构建 Debug APK。

当前阶段：第一部分——工程骨架、主题、底部导航和四个基础页面。
